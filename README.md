# LAS 高反小球点云检测工具

对扫描仪采集的 LAS/LAZ 格式点云进行坐标系转换、高反射率小球强度过滤与聚类、两份点云误差分析，以及点云手动初配准 + GICP 精配准。统一桌面工作台使用 PySide6/OpenGL 显示点云，四类功能可以相互配合，也可以单独使用。

---

## 环境要求

- **Python** 3.9 或以上（推荐 3.11/3.12）
- **操作系统**：Windows（中文字体依赖 Microsoft YaHei；其他系统可正常运行但中文标注可能显示方框）
- 支持 OpenGL 3.3 的显卡及驱动（独显或核显均可；推荐独显）

启动时可以不传点云。进入工作台后，功能一、二、三、四都可以在各自页面选择点云文件。也可以传入一份点云作为初始显示：


### 四个主要功能

程序打开 **LAS 高反球检测 - GPU 工作台** 后，左侧标签页按功能拆分：

| 功能 | 入口 | 主要用途 | 主要输出 |
|------|------|----------|----------|
| 1. 坐标系转换 | `1 坐标系` | 拟合标定房方向，选择 X/Y 轴、原点和附加旋转 | 转换后的完整 LAS |
| 2. 强度过滤与聚类 | `2 强度` + `3 聚类审核` + `4 导出` | 打开点云，强度过滤，DBSCAN 提取小球点，人工剔除 | CSV、聚类球心 LAS、完整 LAS/PCD |
| 3. 两份点云误差分析 | `5 点云对比` | 选择两份点云，分析主要平面距离差、角度差，并辅助统计最近邻误差 | 界面统计结果与误差着色视图 |
| 4. 手动初参 + GICP | `6 点云配准` | 选择目标聚类点云和动捕点云，手动旋转/平移后 GICP 精配准 | 4×4 变换矩阵、R、t |

右侧 OpenGL 点云视图在所有功能中保持可用。程序最多向 GPU 上传稳定抽样点，避免千万级点云拖慢旋转；算法和导出仍使用全量数据。窗口顶部会显示实际 OpenGL 渲染器名称。

## 命令参数

```
python las_ball_detector.py <las_file> [选项]
```

### 桌面工作台常用参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `las_file` | 启动时初始打开的 LAS/LAZ 文件；桌面工作台可省略 | 可选 |
| `-p PERCENTILE` | 强度页初始阈值使用的百分位数 | `90` |
| `-e EPS` | 聚类页 DBSCAN 初始搜索半径；不填则默认自动估算 | 自动估算 |
| `-m MIN_SAMPLES` | 聚类页 DBSCAN 初始最小点数 | `5` |
| `-o OUTPUT` | 导出页默认输出文件名前缀 | `ball_centers` |

### 批处理兼容参数

| 参数 | 说明 |
|------|------|
| `--no-viz` | 不打开桌面工作台，按旧批处理流程直接过滤、聚类、导出 |
| `-t THRESHOLD` | 批处理模式下使用固定强度阈值 |
| `-i` | 旧交互阈值参数；桌面工作台中不需要使用 |
| `--coord-frame` | 旧坐标系前置参数；桌面工作台中已由 `1 坐标系` 标签页替代 |

# 打开桌面工作台

## 功能说明

### 1. 读取点云

支持 LAS 1.0–1.4 及 LAZ（压缩）格式。自动读取 XYZ 坐标和强度值，输出点数、强度统计信息。

> **CloudCompare BIN2 文件（.bin / .las 签名为 CCB2）**：需先用 CloudCompare 转换：
> ```powershell
> & "C:\APP\CC\CloudCompare\CloudCompare.exe" -SILENT -O "input.bin" -C_EXPORT_FMT LAS -SAVE_CLOUDS
> ```

---

### 2. 功能一：坐标系转换并导出 LAS

在 `1 坐标系` 标签页定义新坐标系，并导出转换后的完整 LAS。

初始状态保持输入 LAS 的实际坐标不变：X/Y/Z 使用原始坐标方向，原点为 `(0,0,0)`。如果不选择新轴或新原点，点击确认后不会执行坐标变换。“拟合盒中心”和“角点”仅作为可选的新原点。

**统一工作台操作步骤：**

1. 在“打开点云”中选择 LAS/LAZ，点击 **打开点云并拟合坐标系**。
2. **选择 X/Y 方向**：从红、绿、蓝三个拟合交线方向中选择；也可选择“自定义”并输入 `x,y,z`
3. **切换正/反向**：分别设置 X、Y 的正向或反向，Z 轴自动按右手系计算
4. **选择坐标原点**：选择世界原点、拟合盒中心或 8 个角点之一
5. **附加旋转**：可输入绕当前 X/Y/Z 的旋转角度
6. 右侧实时显示当前坐标系：黄色大点为原点，粗红/绿/蓝线分别为 X/Y/Z 轴
7. 点击 **应用坐标系**
8. 在“坐标系转换结果”中选择输出路径，点击 **导出当前坐标系 LAS**

交线显示规则：
- 红色交线：RANSAC 拟合后的长边方向组
- 绿色交线：RANSAC 拟合后的中边方向组
- 蓝色交线：RANSAC 拟合后的短边方向组

X 轴和 Y 轴必须选择不同颜色的非平行交线；选择同方向交线时界面会提示重新选择。

如果自动拟合盒体失败，程序不会退出，会保持原始坐标系。此时仍可使用自定义 X/Y 方向和世界原点导出。

### 3. 功能二：打开点云、强度过滤、聚类点结果

功能二由 `2 强度`、`3 聚类审核`、`4 导出` 三个标签页组成。

操作步骤：

1. 在 `2 强度` 页点击 **打开点云用于强度过滤和聚类**，可重新选择 LAS/LAZ。
2. 拖动强度阈值，右侧 GPU 视图会预览保留点。
3. 点击 **应用过滤并进入聚类**。
4. 在 `3 聚类审核` 页设置 DBSCAN 参数，点击 **运行聚类**。
5. 聚类表格会列出 ID、点数、强度范围、中心坐标和样本点号。
6. 取消“保留”复选框即可剔除，重新勾选可恢复。
7. 鼠标靠近右侧黄色/红色聚类中心点，会显示聚类 ID 和中心坐标。
8. 在 `4 导出` 页导出 CSV、聚类球心 LAS、完整 LAS 或 PCD。

对强度过滤后的点进行 DBSCAN 密度聚类，提取高反射率小球。

- **eps 自动估算**：对过滤点云采样，计算 k-NN 距离曲线，取第 95 百分位值
- 每个聚类中心使用**强度加权重心**，减少低强度拖尾造成的偏移

---

### 4. 功能三：两份点云主面匹配并分析误差

在 `5 点云对比` 标签页使用。

常用流程：

1. 在“直接选择两份点云用于误差分析”中分别选择第一份和第二份 LAS/LAZ。
2. 设置 **最大匹配距离**，用于排除过大误差，并作为颜色深浅上限。
3. 设置 **体素大小**，用于对两份点云降采样。
4. 点击 **运行点云对比分析**。

只要两份路径都已选择，点击运行会自动加载并对比；“加载第一份/加载第二份”按钮主要用于提前预览或确认点云。

结果会显示：

- 两份点云拟合出的 3 组主要平面方向匹配关系
- 3 个主方向的角度差
- 6 个主面的距离差（次点云面 - 主点云面）
- 第一份/第二份降采样点数
- 有效点对数量和有效率
- RMSE、平均距离、中位距离、95%/99% 分位距离、最大有效距离
- 右侧视图优先按“第二份点云到对应主面的偏差”着色：颜色越浅偏差越小，颜色越深偏差越大，深红表示超过最大匹配距离

如果第二份点云与第一份不在同一坐标系，也可以使用页面中的“加载第二份点云并拟合坐标系”流程，先拟合并应用第二份点云坐标系，再运行误差分析。

### 5. 功能四：目标点云 + 动捕点云手动初参和 GICP

在 `6 点云配准` 标签页使用。典型场景是：

- **目标点云（绿色）**：功能二导出的聚类球心 LAS，或当前功能二中保留的聚类球心。
- **源点云（红色）**：动捕生成结果转换后的点云，通常只有 30–100 个点；支持 LAS/LAZ，也支持直接读取 TRC 第一帧。

操作步骤：

1. 在“目标点云（绿色，聚类结果）”中加载聚类球心 LAS。若不加载，程序默认使用功能二当前保留的聚类球心。
2. 在“源点云（红色）”中加载动捕点云 LAS/LAZ，或直接选择 `.trc` 文件。TRC 会取第一帧，把 `Frame# Time Timestamp` 后面的 XYZ 三元组作为源点云。
3. 如动捕坐标单位不是米，设置单位缩放系数，例如 TRC 表头单位为 `mm` 时填 `0.001`。
4. 点击 **激活交互变换模式**。
5. 在“视图与坐标系”中选择视图，并按需要调整 **平移步长**：
   - `俯视 XY`：鼠标平移映射到 X/Y
   - `前视 XZ`：鼠标平移映射到 X/Z
   - `右视 YZ`：鼠标平移映射到 Y/Z
   - `自由视图/等轴测`：按当前相机平面移动
6. 在右侧视图中拖动红色源点云：
   - 左键拖拽：旋转
   - `Shift + 左键` 或右键拖拽：按当前视图平面做真实坐标平移
7. 点击 **提交变换** 保存手动初参。
8. 也可用“精确旋转 & 平移”输入数值增量。
9. 设置 GICP 初始最大对应距离，点击 **运行 GICP 配准**。程序会自动做多阶段配准：第一轮使用该距离，之后每轮减少 `0.01 m`。每个阶段都会重新创建源/目标点云、重新估计法向，并从当前手动初参重新跑 GICP，阶段之间互不继承。

目标点云和源点云都支持单独勾选显示/隐藏，也可以点击清除按钮移除当前加载结果。
右侧会显示世界坐标系：红色为 X，绿色为 Y，蓝色为 Z。交互平移使用固定的真实坐标步长，不再随视图缩放改变。

GICP 结果区会输出：

- 多阶段记录：每阶段最大对应距离、匹配点数、fitness、RMSE
- 自动采用阶段：在匹配点数不低于 90%（fitness >= 0.90）的阶段中选择 RMSE 最小的结果
- `T_gicp`：GICP 增量变换
- `T_manual`：手动初参变换
- `T_full = T_gicp @ T_manual`
- 完整 `R` 旋转矩阵和 `t` 平移向量

| 文件名 | 内容 | 生成条件 |

## 常见问题

**Q: 运行报 `Invalid file signature "b'CCB2'"`**  
A: 输入文件是 CloudCompare BIN2 格式，需先转换为标准 LAS：
```powershell
& "C:\APP\CC\CloudCompare\CloudCompare.exe" -SILENT -O "your_file.bin" -C_EXPORT_FMT LAS -SAVE_CLOUDS
```

**Q: 顶部 GPU 信息显示软件渲染器或界面仍卡顿**  
A: 更新 NVIDIA/AMD/Intel 显卡驱动，并在 Windows“图形设置”中将 `.venv\Scripts\python.exe` 设置为高性能。当前工作台会显示实际 OpenGL renderer；本机验证示例为 `NVIDIA GeForce RTX 5060 Laptop GPU`。

**Q: 点击 GICP 报 `GICP 需要 open3d`**  
A: 安装可选依赖：
```powershell
.\.venv\Scripts\python.exe -m pip install open3d
```

**Q: 找不到任何聚类**  
A: 尝试以下调整：
- 在 `2 强度` 页降低强度阈值
- 在 `3 聚类审核` 页增大 eps
- 在 `3 聚类审核` 页减小最小点数

**Q: 聚类中心偏离小球**  
A: 可能是低强度拖尾点影响了加权重心。尝试提高强度阈值以减少拖尾点。
